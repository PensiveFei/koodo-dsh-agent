# 截图（showcase）

README 的「实际效果」小节引用这里的图片。

## 约定

- 文件名：`showcase-<内容>.png`，全小写、连字符分隔
- 引用方式：README 里用 **raw 绝对链接**（这样在 npm / 镜像站看 README 也能显示）

  ```markdown
  ![智能体面板](https://raw.githubusercontent.com/PensiveFei/koodo-dsh-agent/main/docs/showcase/showcase-panel.png)
  ```

## 建议的几张

| 文件名 | 内容 | 要点 |
| --- | --- | --- |
| `showcase-panel.png` | 阅读界面右下角的智能体面板（展开、有对话） | 让人一眼看到「面板长在阅读器里」 |
| `showcase-progress.png` | 面板底部的进度条（`第 N 步 · pwsh：… · 34s`） | 这是本项目相对普通 AI 助手的差异点 |
| `showcase-translate.png` | 划词翻译面板，服务选的是 `DSH Agent` | 证明划词也走智能体 |
| `showcase-tool.png` | 智能体真的动了文件/命令（例如帮你补了书库元数据） | 证明「有工具能力」不是嘴上说说 |

## 截图前注意

截图里不要出现：真实姓名、邮箱、书库路径里的用户名、其它窗口的隐私内容。
需要的话先把 Koodo 窗口缩到只露出阅读区。
